# Class Design

## Overview
The class design defines the main classes of the Student Management System and their responsibilities.

The design will evolve as new features are added in each phase.

## Phase 1 Classes

### Student
**Main Data:**
- id (system-generated)
- full name
- age
- course (enum)

**Services:**
- CRUD
- Search
- Get all students
- Validate student operations

**Repository**
- Interacts with storage and service
